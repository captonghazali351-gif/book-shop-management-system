# Book Shop Management System

A responsive Book Shop Management System built with HTML, CSS, and JavaScript.

## Features

- Dashboard with sales and inventory statistics
- Add, edit, search, filter, and delete books
- Stock management
- Low-stock alerts
- Duplicate book protection
- Create and manage sales
- Automatic sale calculation
- Automatic stock reduction
- Sales history
- Customer management
- Revenue and sales reports
- Shop settings
- Admin profile and password management
- LocalStorage data persistence
- Responsive design for desktop and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Font Awesome
